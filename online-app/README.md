# نشر المساعد الذكي «استشر طبيبك العام»

هذه نسخة متصلة بواجهة OpenAI Responses API. لا تعمل واجهة API على GitHub Pages؛ انشر هذا المجلد على Vercel، ثم شارك رابط Vercel الناتج.

## خطوات النشر

1. افتح مشروع GitHub `tamerrommel3284/istashir-tabibak-landing` في Vercel واختر Import Project.
2. في إعدادات المشروع، اجعل **Root Directory** هو `online-app`.
3. من **Settings → Environment Variables** أضف `OPENAI_API_KEY` بمفتاح API الخاص بك. أدخله في لوحة Vercel فقط؛ لا تضعه في GitHub أو ملفات الصفحة أو المحادثات.
4. (اختياري) أضف `OPENAI_MODEL` وحدد نموذجًا متاحًا لحساب API لديك. القيمة الافتراضية في الخادم `gpt-6.1-sol`؛ إذا لم يتوفر لحسابك غيّرها إلى نموذج متاح.
5. أعد النشر بعد إضافة المتغيرات، ثم استخدم عنوان `*.vercel.app` الذي يعرضه Vercel.

مفتاح OpenAI API والفوترة منفصلان عن اشتراك ChatGPT. لا يعمل الإرسال الفعلي قبل إعداد مفتاح صالح وتمكين الفوترة المناسبة.

## ما يفعله التطبيق

- يرسل نص المحادثة إلى `/api/chat` بعد موافقة الزائر الظاهرة، ويرسل الصورة عند إرفاقها فقط.
- يحتفظ بسياق المحادثة في ذاكرة صفحة المتصفح الحالية؛ لا يحفظه في Local Storage ولا يكتب محتوى الرسائل في سجلات الخادم عمدًا.
- يستخدم `store: false` في Responses API ويعرض روابط الاستشهادات التي يعيدها بحث الويب عند استخدامها.
- يعمل كمساعد معلومات صحية عام، وليس طبيبًا أو خدمة طوارئ أو وسيلة تشخيص. راجع `privacy.html` وداخل الصفحة قبل فتح الخدمة للجمهور.

حد الطلبات الحالي بسيط وذاكرته مؤقتة لكل نسخة خادم. قبل الترويج الواسع، استبدله بحدود دائمة وتحقق من لوحة Vercel وOpenAI لمراقبة الاستخدام والتكلفة.
