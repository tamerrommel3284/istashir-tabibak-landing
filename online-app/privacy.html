بيان الخصوصية

آخر تحديث: 22 أكتوبر 2026

هذه الصفحة أداة معلومات صحية عامة تعمل بالذكاء الاصطناعي. ليست طبيبًا بشريًا ولا تشخّص ولا تقدم رعاية طارئة.

ما الذي يُرسل؟

بعد وضع علامة الموافقة والضغط على «إرسال»، تُرسل الرسالة وسياق المحادثة الجاري والصورة المرفقة (إن وجدت) من خادم الموقع إلى OpenAI API لتوليد رد. لا ترسل صورة قبل موافقتك. لا ترفع أسماء أو أرقام ملفات أو معلومات تعريفية؛ أخفِ هذه البيانات من الصور قبل إرسالها.

التخزين والاحتفاظ

لا يخزن هذا التطبيق سجل المحادثات في قاعدة بيانات أو Local Storage. يطلب من OpenAI API عدم تخزين كائن الرد باستخدام store:false. لكن OpenAI تذكر أن سجلات مراقبة إساءة الاستخدام قد تحتفظ بمحتوى API لمدة تصل إلى 30 يومًا افتراضيًا؛ تختلف الاستثناءات والإعدادات حسب الأهلية والسياسة. راجع ضوابط البيانات لدى OpenAI وسياسة الخصوصية.

معلومات حساسة

المعلومات الصحية والصور المرفوعة حساسة. أرسل الحد الأدنى اللازم فقط. لا تستخدم الخدمة لحالات طارئة، ولا ترسل صور أشعة CT أو MRI بغرض التشخيص. عند وجود أعراض خطيرة، اتصل بخدمات الطوارئ المحلية فورًا.

الجهات المقدمة للخدمة

يستضيف مشغل الموقع التطبيق عبر Vercel، وتُعالج الطلبات عبر OpenAI API. راجع سياسات مزودي الخدمة لأي تفاصيل إضافية عن المعالجة والاحتفاظ.
